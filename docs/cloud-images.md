# Загрузка изображений

Файлы отправляются браузером напрямую в Cloudinary. API приложения и PostgreSQL получают только HTTPS-ссылку. Настройки читаются во время запуска, пересобирать React для их изменения не нужно.

1. Создайте аккаунт Cloudinary и найдите Cloud name.
2. Создайте Upload preset с режимом Unsigned. Ограничьте допустимые форматы JPG/PNG/WebP и размер 5 МБ в самом preset; ограничения браузера не заменяют правила облачного сервиса. Выделите отдельную папку для проекта.
3. На Render добавьте `Cloudinary__CloudName` и `Cloudinary__UploadPreset` в Environment и перезапустите сервис.
4. В профиле перетащите изображение в поле фотографии. Проверьте появление файла в Cloudinary и сохранение ссылки в профиле после автосохранения.

API secret в браузер не передаётся и для unsigned preset не нужен. Имя preset доступно клиенту; контролируйте объём загрузок и ограничения в Cloudinary.

Без этих настроек приложение работает, но загрузка файлов отключена. Ввод существующей ссылки остаётся доступен; сам по себе он не считается выполнением требования drag-and-drop.

Документация: https://cloudinary.com/documentation/upload_images#unauthenticated_requests
