# CV Platform → Odoo

Модуль рассчитан на Odoo 19 Community или Enterprise с поддержкой Python-модулей: собственный сервер либо Odoo.sh. Обычный Odoo Online не позволяет установить этот модуль.

## Что реализовано

- Рекрутеры и администраторы выпускают, перевыпускают и отзывают токен в редакторе позиции.
- Токен относится только к одной позиции. В PostgreSQL хранится только SHA-256 хеш; исходный токен показывается один раз.
- `GET /api/integrations/odoo/position` принимает `Authorization: Bearer cvp_...`; JWT пользователя, токены других позиций и query-параметры не дают доступ к произвольной позиции.
- Экспорт содержит атрибуты текущего шаблона и значения текущих профилей с опубликованными резюме на эту позицию. Черновики не учитываются. После обновления профиля следующий импорт получает обновлённые агрегаты.
- Числа: минимум, максимум, среднее. Строки, текст, списки и логические значения: пять самых частых значений. Даты: ранняя и поздняя. Периоды: раннее начало, позднее завершение, средняя длительность завершённых периодов и число открытых периодов.
- Для встроенных полей и изображений экспортируется только число заполненных/пустых значений; имена кандидатов, фото и индивидуальные резюме не передаются.
- Импорт сохраняет позицию, атрибуты и результаты в Odoo. Повторный импорт обновляет ту же позицию и заменяет устаревшие атрибуты. Токен не сохраняется в импортированной позиции; успешный импорт удаляет временную форму с токеном.
- Обычные внутренние пользователи Odoo могут смотреть результаты и запускать импорт, но не изменять или удалять импортированные записи. Настройка адреса доступна администратору.

## Сначала задеплой CV Platform

Отправь изменения проекта на GitHub и дождись успешного деплоя Render. Миграция `AddPositionExportTokens` применяется при старте API. Дополнительные environment variables для интеграции Odoo в CV Platform не нужны.

## Временный бесплатный деплой на Render

Для демонстрации на 10 дней можно использовать отдельные Free Web Service и Free PostgreSQL. У Free Web Service только 512 МБ памяти: установка или работа Odoo может завершиться из-за нехватки памяти. Этот способ не проверен на реальном Render. База действует 30 дней с момента создания; локальное файловое хранилище не сохраняется при перезапуске. Запуск ниже переводит вложения Odoo в PostgreSQL до открытия HTTP-сервера. Сессия входа может потеряться при перезапуске, тогда войди заново.

1. Отправь код в GitHub.
2. В Render создай отдельную PostgreSQL базу на Free, имя сервиса `cvplatform-odoo-db`, имя базы `cvplatform_odoo`. Выбери тот же регион, что и будущий Odoo. Если Render не разрешает ещё одну бесплатную базу в workspace, этот сценарий требует отдельного workspace с доступным Free тарифом или другой отдельной PostgreSQL базы. Не используй базу CV Platform.
3. Скопируй Internal Database URL новой базы.
4. Создай Web Service из того же GitHub-репозитория, имя `cvplatform-odoo`, runtime Docker, тариф Free, тот же регион. Root Directory оставь пустым, Dockerfile Path укажи `integrations/odoo/Dockerfile.render`, Docker Build Context Directory — `.`. Docker Command не задавай.
5. Добавь environment variables: `DATABASE_URL` — Internal Database URL новой базы; `ODOO_MASTER_PASSWORD` — длинный случайный мастер-пароль; `ODOO_ADMIN_LOGIN` — `admin` или твоя почта; `ODOO_ADMIN_PASSWORD` — другой длинный случайный пароль для входа. Не вставляй название переменной в её значение. `PORT` Render задаёт автоматически.
6. Health Check Path укажи `/web/login`. Запусти деплой. Первый запуск устанавливает базу и наш модуль автоматически. В логах после успешной инициализации появится `Odoo initialization complete; starting HTTP server`. Не перезапускай сервис во время первичной установки.
7. Открой публичный URL сервиса, войди с `ODOO_ADMIN_LOGIN` и `ODOO_ADMIN_PASSWORD`. Создавать базу через браузер и вручную устанавливать модуль не нужно: менеджер баз отключён.
8. CV Platform → Configuration: сохрани `https://cvplatform-h1rj.onrender.com`. На нашем сайте сгенерируй токен позиции, в Odoo открой Import position и вставь токен.

Пароль администратора применяется только при первой настройке: изменение `ODOO_ADMIN_PASSWORD` в Render после первого запуска не сбрасывает пароль существующего пользователя. Меняй его в интерфейсе Odoo.

Free сервис засыпает после 15 минут без запросов. Бесплатные часы общие для workspace, поэтому учитывай уже работающий CV Platform. Перед записью демонстрации открой оба сайта заранее. Сохрани резервную копию базы до окончания бесплатного срока. Не публикуй URL базы или пароли в репозитории.

Источники: [Free Render](https://render.com/docs/free), [Compute plans](https://render.com/docs/compute-plans).

## Локальный запуск отдельного Odoo с Docker

Установи и запусти Docker Desktop. Из корня проекта:

```powershell
cd integrations/odoo
Copy-Item .env.example .env
Copy-Item odoo.conf.example odoo.conf
```

В `.env` замени `ODOO_DB_PASSWORD` на случайный пароль. В `odoo.conf` замени `admin_passwd` на другой случайный мастер-пароль. Эти локальные файлы исключены из Git.

```powershell
docker compose up -d
```

Открой http://localhost:8069. Создай базу, например `cvplatform_odoo`: введи мастер-пароль из `odoo.conf`, email и пароль администратора Odoo. Отключи демонстрационные данные, если они не нужны.

В Odoo:

1. Открой Settings и включи developer mode.
2. Открой Apps → Update Apps List → Update.
3. Найди `CV Platform Position Viewer` и нажми Activate/Install.
4. Открой CV Platform → Configuration. Укажи `https://cvplatform-h1rj.onrender.com` и нажми Save.
5. На нашем сайте войди как рекрутер/администратор, открой редактор существующей позиции, сохрани изменения и нажми «Сгенерировать API-токен». Скопируй токен.
6. В Odoo открой CV Platform → Import position, вставь токен и нажми Import position.
7. Откроется карточка с атрибутами и агрегатами. Все импорты видны в Imported positions.

Для подключения к локальному API из Docker можно временно указать `http://host.docker.internal:5242`. API должен слушать адрес, доступный контейнеру. Для демонстрации рекомендуем использовать уже задеплоенный сайт на Render.

## Если Odoo уже развёрнут

Скопируй каталог `addons/cvplatform_position_viewer` в каталог custom addons своего Odoo 19, добавь родительский каталог в `addons_path`, перезапусти Odoo и выполни шаги установки выше. На Odoo.sh добавь модуль в Git-репозиторий проекта; после сборки обнови список приложений и установи модуль.

Compose по умолчанию открывает Odoo только на локальном компьютере. Для публичного экземпляра разверни его на своём сервере с постоянными volumes и HTTPS reverse proxy, включи `proxy_mode = True`, после создания базы настрой `dbfilter` и отключи менеджер баз через `list_db = False`. Не удаляй volumes при обновлении — в них хранятся база и вложения Odoo.

## Демонстрация для задания

Создай несколько опубликованных резюме на одну позицию с разными числами и повторяющимися текстовыми значениями. Покажи генерацию токена, импорт в Odoo, список позиций и подробную карточку. Измени одно значение профиля, повтори импорт тем же токеном и покажи изменившиеся агрегаты без новой записи позиции. Перевыпусти токен и покажи отказ при использовании старого токена, затем успешный импорт новым. Для выполнения требования о развёрнутом экземпляре покажи адрес своего публичного Odoo и его работающий интерфейс.

## Проверки

```powershell
dotnet run --project tests/CvPlatform.OdooChecks
python -m unittest discover -s integrations/odoo/checks -v
```

В установленном Odoo можно запустить ORM-проверки модуля в отдельной тестовой базе:

```powershell
docker compose run --rm odoo odoo -d cvplatform_odoo_test -i cvplatform_position_viewer --test-enable --test-tags /cvplatform_position_viewer --stop-after-init --http-port=8070
```

Не используй рабочую базу для тестов.
